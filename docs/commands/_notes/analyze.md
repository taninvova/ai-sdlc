## Usage

**Shortcut.** `/fc:analyze` is the US spelling of [`/fc:analyse`](analyse.md): the same task, not
a deprecated one. It runs the analyse task with the same input, takes the same arguments and modes,
and writes what `/fc:analyse` writes. It shows no notice. Codex has `$fc-analyze`, and headless
`TASK=analyze` runs the analyse task too. To pin a model, map `analyse` in `ai-factory/models.yaml`.
