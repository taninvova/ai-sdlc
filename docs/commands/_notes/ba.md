## Usage

**Shortcut.** `/fc:ba` is a shorter name for [`/fc:analyse`](analyse.md): the same task, not a
deprecated one. It runs the analyse task with the same input, takes the same arguments and modes,
and writes what `/fc:analyse` writes. It shows no notice. Codex has `$fc-ba`, and headless
`TASK=ba` runs the analyse task too. To pin a model, map `analyse` in `ai-factory/models.yaml`.
