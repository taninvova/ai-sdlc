## Usage

**Shortcut.** `/fc:scout` is a shorter name for [`/fc:explore`](explore.md): the same task, not a
deprecated one. It runs the explore task with the same input, takes the same arguments, and writes
what `/fc:explore` writes. It shows no notice. Codex has `$fc-scout`, and headless `TASK=scout`
runs the explore task too. To pin a model, map `explore` in `ai-factory/models.yaml`.
